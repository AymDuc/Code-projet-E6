# Fiche descriptive - Realisation professionnelle 1

## Nom du projet
Planning Hotel Hinano

## Contexte
Le projet consiste a developper une application web permettant de gerer les reservations d'un hotel. L'objectif est de remplacer une gestion manuelle par un planning numerique plus lisible, accessible et fiable.

## Besoin initial
- Visualiser les reservations par chambre et par date.
- Ajouter, modifier et supprimer une reservation.
- Eviter les erreurs de planning.
- Suivre les repas, les transferts et les informations client.
- Proteger l'acces a la partie administration.

## Technologies utilisees
- PHP pour le back-end et les API.
- MySQL pour la base de donnees.
- HTML, CSS et JavaScript pour l'interface.
- XAMPP / phpMyAdmin pour l'environnement de developpement.

## Fonctionnalites principales
- Connexion administrateur.
- Planning interne des reservations.
- Ajout, modification et suppression de reservations.
- Export CSV.
- Page publique de disponibilites.
- Gestion des repas, transferts, factures et notes.

## Modalites d'acces aux elements techniques
- Code source : `Projet_Planning_Hotel/Code_Source/`
- Script SQL : `Projet_Planning_Hotel/Base_De_Donnees/planning_hotel.sql`
- Page principale admin : `planning.php`
- Page de connexion : `login.php`

## Identifiants de test
Pour la version examen/local :
- Identifiant : `admin`
- Mot de passe : `admin123`

Ces valeurs sont modifiables dans `login.php` ou par variables d'environnement.

## Competences mobilisees
- Developper la presence en ligne d'une organisation.
- Travailler en mode projet.
- Mettre a disposition un service informatique.
- Gerer une base de donnees.
- Securiser une application par authentification.

## Simplification pour l'oral
Pour la demonstration, il est conseille de montrer uniquement : connexion, creation d'une reservation, modification, suppression, export CSV et consultation de la base SQL.
