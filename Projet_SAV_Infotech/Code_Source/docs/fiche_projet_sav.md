# Fiche descriptive - Infotech SAV Manager

## Contexte

Dans une boutique informatique, les appareils déposés en SAV doivent être suivis correctement : réception, diagnostic, attente client, réparation, restitution.

## Problème rencontré

Le suivi manuel peut entraîner des oublis, une perte d'information ou un manque de visibilité sur l'état des réparations.

## Solution proposée

Développement d'une application desktop Windows permettant de centraliser les interventions SAV dans une base locale SQLite.

## Fonctionnalités

- Création d'une fiche intervention
- Modification du diagnostic et du statut
- Suppression d'une intervention
- Recherche rapide
- Export CSV

## Ressources logicielles

- Visual Studio Community
- .NET 8
- C#
- Windows Forms
- SQLite

## Ressources matérielles

- PC Windows 10 ou Windows 11

## Modalités d'accès

L'application est accessible localement sur un poste Windows.
Le projet peut être ouvert avec Visual Studio via le fichier `InfotechSAVManager.csproj`.

## Compétences mobilisées

- Développement d'application
- Gestion d'une base de données
- Interface utilisateur
- Validation de formulaire
- Export de données
